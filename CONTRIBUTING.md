# Contributing to Teader

We love your input! We want to make contributing to Teader as easy and transparent as possible.

## Pull Requests

1. Fork the repo and create your branch from `main`.
2. Install dependencies with `npm install`.
3. If you've added code that should be tested, add tests under `tests/`.
4. Ensure the test suite passes (`npm test`).
5. Format your commit messages following Conventional Commits (`feat:`, `fix:`, `docs:`, `refactor:`).
6. Issue that pull request!

## Issues

Use GitHub Issues to report bugs and suggest features. Please use the provided issue templates.
